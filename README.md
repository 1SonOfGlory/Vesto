# Vesto storefront prototype

A small apparel storefront built with HTML, CSS, browser JavaScript, and a Node HTTP server. The server accepts demonstration orders and stores them in a local JSON file.

Run `node serve.js` from this directory and open the localhost address printed by the server. No package installation is needed. The `data/` directory is created locally and is excluded from version control.

This is a local prototype. Order endpoints do not provide production authentication, concurrency control, payment settlement, or durable storage. Use fictional orders only. Product photographs and existing order data are not included in this source release; replace image references with assets you are licensed to use.
